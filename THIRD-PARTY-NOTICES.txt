Application
-----------
MP4 Shrinker invokes FFmpeg/ffprobe through their command-line interface using
separate processes. It does not link FFmpeg libraries into its C# application.
The app's source code and tests are supplied separately with this delivery.
The app uses no additional third-party NuGet UI or MVVM framework.
