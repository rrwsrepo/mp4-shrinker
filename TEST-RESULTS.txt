NOT RUN IN THIS ENVIRONMENT
- Native Windows app launch, keyboard interaction and layout at different DPI.
- The exact bundled Windows FFmpeg/ffprobe executables.
- GPU driver/device encoding (NVIDIA NVENC, Intel QSV, AMD AMF).
- A clean Windows machine without a separately installed .NET runtime.
- Windows source-file locks, protected paths/ACLs and long-path OS policy.
- Actual power-off or cancellation of the Windows shutdown countdown.
- Physical disk-full or removable-drive removal simulation.
- Hours-long/high-volume media or human playback and A/V sync review.

WINDOWS SMOKE-TEST CHECKLIST
1. Extract the full portable ZIP and launch MP4-Shrinker.exe.
2. Check system light/dark mode, keyboard focus, 100/150/200% DPI and resizing.
3. Scan a test folder with nested Unicode filenames. Start using defaults.
4. Play the output and check orientation, audio sync, subtitles and chapters.
5. Cancel while encoding. Confirm no final/temporary incomplete MP4 remains.
6. Close during encoding and reopen; completed outputs must remain untouched.
7. Re-run unchanged settings and confirm existing verified outputs are skipped.
8. Select a GPU mode and check the real encoder test and CPU fallback message.
9. Test low-space/unwritable output handling and verify source file hashes.
10. Enable shutdown only on a suitable test machine, then cancel the countdown.

LIMITS
HDR and unusual streams/pixel formats are refused rather than transformed.
Compression is lossy and savings vary. Stream validation is not a perceptual
quality metric or a complete second decode. No claim of native Windows/GPU
runtime testing is made by this report.
